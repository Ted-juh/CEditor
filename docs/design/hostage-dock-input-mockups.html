1 · A vocal input in the dock: the INPUT block and its pages

An input part has an INPUT block where an instrument part has its instrument: the connection it plays from, its meter before anything else, its trim, whether it is muted, and how late the singer hears themselves. Here it opened muted, as every input part does. Its effects work as any part's do; the harmoniser takes its notes from the keys part.

2 · A guitar input with the tuner open

Pad 3 on the INPUT page opens the TUNER, a built-in. While it is open the part is silent, as with a pedal tuner; closing it brings the sound back. The same tuner is on the Stage screen and opens from a footswitch.
