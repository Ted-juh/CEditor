2 · Map the show to this interface (step 2b)

The show names what it needs; this screen says where each one is on this interface, once. Inputs are mapped by playing: sing, play or speak into it and the channel that lights is chosen. Outputs get a short, quiet ident. MIDI ports are found by name, and asked about only when two share a name. The mapping is kept for this interface, so the same model on any computer needs nothing.

3 · The line check, on the CTRL49

Before the doors open, one walk through every connection of the show: speak into each mic, play each instrument, hear each output's ident. Each one lights as it is heard and is ticked. Knob 1 walks the list; the pads confirm, ident, skip or go back. The same list is in the dock under the utility's Line check.

What it checks

  • Every input arrives: a signal on its mapped channel, and no clip.
  • Every output is heard: its ident played, ticked by hand.
  • Every MIDI port answers: a key or a knob from it.

What it does not

  • Set levels: that is Soundcheck's Measure, song by song.
  • Change any mapping: a connection that fails opens the mapping screen in the dock.
