2 · One control at a time

Select a control and its settings open, in words. A knob: what it moves, the short label the keyboard shows (made for you, up to eight letters, yours to change), the range by showing, steps and direction. A pad: up to four layers, each moving a parameter, switching a parameter between two values, or running a command from the same list the palette uses.

3 · Copy a page to another part

The Bass page, made for Diva on Moog Bass, copied to Warm Pad, which runs Pigments. Each knob is offered Pigments' parameter of the same or a similar name, by the same rules as swapping a plug-in. Macros and commands go across unchanged. The copy is a new page; the original stays where it is used.
