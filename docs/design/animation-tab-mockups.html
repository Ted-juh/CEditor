The Animation tab

Two of the seven properties the editor offers animate nothing at all. The list of what an animation changes is a box of raw JSON. And easing is four words with no picture.

Built on 2026-09-10. The space argument was measured first and rejected — the section does not grow. What is built rests on four findings, each checked against the shipped code before this page was written, and one of them was corrected by that check.

The other two sections the candidate list counted — Animation in Display and PixelDisplay — are a different feature. They play a GIF or a sprite sheet behind a dot-matrix screen. The list grouped the three by name. They stay where they are.

So this is not built for the space. It is built for what follows.

Plate 2

Two of the seven do nothing

The runtime accepts a fixed list of paths and fills one of three buckets — transform, opacity, size. There is no colour bucket. The editor's dropdown offers two colour properties anyway. Measured, by running the real runtime over each of the seven and reading back which buckets it filled:

Pick one of those two, click Append target, and you get an animation that never runs. Nothing says so. That check is now a test: it runs the real runtime over every property this tab offers and asserts the tab's answer matches, so if the runtime ever grows a colour bucket the test fails rather than the tab keeping a warning that is no longer true.

Plate 5

The warning is under the dropdown while the button is still unpressed. The header counts the dead targets across every animation on the control, not just the open one.

Decided while building

  • Width and Height are offered here and not in the panel. The runtime animates both, and the panel's dropdown has never listed them. The same test that pins the two dead ones pins the panel's list at seven, so if the panel ever grows, this claim fails with it.
  • The dead properties are kept, not hidden. The panel still offers them, so a control saved from the panel can already carry one. A tab that dropped them could not name the problem.
  • The fourth finding was written down softer after reading the source. The first draft called kind being a free text box a trap. The cell's own hint already says transition is the only kind that works, so the claim was wrong as written. The test now asserts the hint is there.
  • No timeline, which the candidate list wanted. One duration, one delay and one easing per animation — there is nothing to lay out along a time axis that the three numbers do not already say. Keyframes would change that.
  • Nothing was removed. The properties panel still draws every section, still edits every field, JSON box and all, and still has its quick-add buttons.
